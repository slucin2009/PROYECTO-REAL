# Assets - Recursos Multimedia

## Logo Institucional

Lugar: `assets/images/logo_institucion.png`

### Cómo agregar el logo:

1. Obtén la imagen del logo del **Liceo Cristiano Peninsular** en formato PNG
2. Asegúrate de que tenga las siguientes características:
   - Dimensiones: Mínimo 256x256 píxeles (recomendado 512x512)
   - Formato: PNG con canal alfa (transparencia)
   - Nombre exacto: `logo_institucion.png`
3. Coloca el archivo en esta carpeta (`assets/images/`)

### Ubicaciones donde aparecerá el logo:

- Encabezado (AppBar) en todas las pantallas principales
- Se redimensionará automáticamente a 40x40 píxeles en el AppBar
- Si no existe el archivo, se mostrará un placeholder visual con las iniciales "LCP"

### Tamaño recomendado:

- **Ancho:** 512 píxeles
- **Alto:** 512 píxeles
- **Ratio:** Cuadrado o rectangular (se ajustará automáticamente)
- **Fondo:** Transparente (recomendado) o color sólido

### Responsividad:

El logo se adapta automáticamente a diferentes tamaños de pantalla sin deformarse.

---

**Nota:** Si el archivo PNG no se encuentra en esta ubicación, la aplicación mostrará un placeholder visual azul con las iniciales de la institución (LCP).
